计算机语言的执行方式
	编译型语言：代码程序 -> 编译器 -> 可执行文件 -> 二进制代码
		C , C++
		优点：只需要编译一次
		缺点：不能跨平台
	解释型语言：代码程序 -> 解释器 -> 二进制代码
		Python , shell , JavaScript
		优点：可以跨平台
		缺点：多次运行效率低

Java语言的执行方式：先编译（预编译）再解释
	Java代码 -> 编译器 -> 字节码文件.class -> 解释器 -> 二进制代码

Python语言的执行方式：解释
	Python代码 -> 解释器( 编译 -> 字节码文件.pyc -> 解释 ) -> 二进制代码

Python缺点：运行速度慢，不能加密
